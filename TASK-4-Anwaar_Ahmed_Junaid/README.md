# Project 4: General Knowledge Quiz

**DecodeLabs Python Programming Internship – Project 4**  
**Intern:** Anwaar Ahmed Junaid

A simple command-line General Knowledge Quiz that demonstrates **Control Flow** using If-Else logic and a score counter.

## Features
- Asks 3 general knowledge questions
- Checks user answers using if-else
- Keeps a running score (+1 for every correct answer)
- Displays final score at the end
- Gives feedback based on performance

## Concepts Used
- Variables (score counter)
- If-Else logic
- Control Flow
- Input handling
- String methods (`.strip()`, `.lower()`)
- `if __name__ == "__main__"`

## How to Run
```bash
python main.py
```
