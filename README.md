##  Project Breakdown

### 1️⃣ To-Do List
A command-line app to add and view tasks, backed by a Python list.
- **Concepts:** Lists, `.append()`, `enumerate()`, functions, `while` loops
- **Run it:**
  ```bash
  cd TASK-1-Anwaar_Ahmed_Junaid
  python main.py
  ```

### 2️⃣ Expense Tracker
Accumulates multiple user-entered expenses into a running total, with input validation and a graceful exit.
- **Concepts:** Accumulator pattern (`total += amount`), `str → float` conversion, `try/except` error handling, sentinel values
- **Run it:**
  ```bash
  cd TASK-2-Anwaar_Ahmed_Junaid
  python main.py
  ```

### 3️⃣ Random Password Generator
Generates strong, randomized passwords of a user-defined length using Python's standard library.
- **Concepts:** `random` and `string` modules, character-set construction, input validation
- **Run it:**
  ```bash
  cd TASK-3-Anwaar_Ahmed_Junaid
  python main.py
  ```

### 4️⃣ General Knowledge Quiz
A 3-question CLI quiz that checks answers and tracks a running score.
- **Concepts:** `if/elif/else` logic, state management, score counters
- **Run it:**
  ```bash
  cd TASK-4-Anwaar_Ahmed_Junaid
  python main.py
  ```
