# Project 3: Random Password Generator

**DecodeLabs Python Programming Internship – Project 3**  
**Intern:** Anwaar Ahmed Junaid

A simple command-line tool that generates strong random passwords using Python’s built-in `random` and `string` modules.

## Features
- Asks the user for desired password length
- Generates a random, complex password
- Uses letters, digits, and special characters
- Input validation for length
- Option to generate multiple passwords or quit

## Concepts Used
- Importing modules (`random`, `string`)
- String manipulation
- Character sets (`string.ascii_letters`, `string.digits`, `string.punctuation`)
- Input validation
- Functions
- `if __name__ == "__main__"`

## How to Run
```bash
python main.py
```
